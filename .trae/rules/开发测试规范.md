# xqtrader 项目开发规则

## 项目结构与快速启动

详见 [README.md](../../README.md)，包含项目结构说明、环境要求、快速启动、测试运行、静态检查等。

## 关键约定

### 导入路径

- 源码包位于 `src/`，所有业务代码通过 `from framework.xxx import ...` 导入
- 测试子目录的模块通过 `conftest.py` 自动发现并加入 `sys.path`

### 数据库

- 数据源配置在 `datasource.yml`，通过 `${ENV_VAR}` 占位符从 `.env` 读取连接信息
- ORM 模型必须继承 `Base` 或 `AuditedBase`，CRUD 操作遵循 dal-orm skill 规范
- 数据库模型禁止使用主外键关系
- 查库验证、改表结构等操作必须使用 db-tools skill

### 测试

- 测试框架：pytest + pytest-asyncio（strict mode）
- 异步 fixture 使用 `@pytest_asyncio.fixture`，异步测试方法使用 `@pytest.mark.asyncio(loop_scope="session")`
- 数据源 fixture 在 `conftest.py` 中统一管理，测试脚本只关注功能验证
- 环境初始化在 `conftest.py` 中处理，不在测试脚本中重复配置

### 静态检查

- **ruff**：`ruff check src/ tests/`（禁止 `--fix` 自动修复）
- **mypy**：`mypy src/`（禁止 `--fix` 自动修复）
- ruff 配置：target-version=py310，line-length=120，规则集 E/F/I/N/W/UP
- mypy 配置：python_version=3.10，disallow_untyped_defs=true

### PowerShell 命令

- 命令之间使用分号 `;` 分隔
- HTTP 请求使用 `Invoke-RestMethod`，不使用 curl
- 环境变量设置：`$env:KEY="value"`
