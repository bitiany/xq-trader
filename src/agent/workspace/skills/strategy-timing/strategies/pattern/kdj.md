# KDJ 金叉策略（kdj）

> rule_id: `ts_kdj_cross` | 类别: pattern | SPI 插件: KDJPlugin
> 消费因子: `kdj_k`, `kdj_d`, `kdj_j`（预计算因子）

---

## 核心逻辑

KDJ 是经典的随机指标，通过 K 线、D 线、J 线的相对位置判断超买超卖与短期拐点。

- **金叉**：K 线上穿 D 线，且位于低位（K < 30），短期反弹信号。
- **死叉**：K 线下穿 D 线，且位于高位（K > 70），短期回调信号。
- **超买**：J > 100，短期过热，警惕回调。
- **超卖**：J < 0，短期超跌，反弹在即。
- **顶背离/底背离**：价格创新高但 KDJ 不创新高（顶背离），反之底背离。

---

## 信号判定规则

| 信号 | 条件 |
|------|------|
| buy | K 上穿 D（金叉），且 K < 30 或 J < 0（低位） |
| sell | K 下穿 D（死叉），且 K > 70 或 J > 100（高位） |
| neutral | KDJ 位于 30-70 中位区，或金叉/死叉位于中位区（信号弱） |

**前值依赖**：判断金叉/死叉需比较 K_prev、D_prev 与当前 K、D 的相对位置。

---

## 信号权重建议

- 默认权重：1.0
- 低位金叉（K < 20 或 J < 0）：权重 ×1.2，置信度 +0.1
- 高位死叉（K > 80 或 J > 100）：权重 ×1.2，置信度 +0.1
- 中位金叉/死叉（30 < K < 70）：权重 ×0.5，标注「信号弱」
- 顶背离/底背离（与价格比较）：权重 ×1.3，置信度 +0.15

---

## 风险提示

1. KDJ 是**短期指标**，信号频繁，需配合趋势类策略过滤噪音。
2. 强趋势中 KDJ 可能长期处于超买/超卖区，过早反向操作风险高。
3. J 线容易钝化（连续 > 100 或 < 0），不可单独作为反向信号依据。
4. 震荡市 KDJ 信号最有效，趋势市慎用。
5. 顶背离/底背离需配合 RSI 共同确认。
