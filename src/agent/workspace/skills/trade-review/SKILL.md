# 交易复盘

按标的查询历史成交记录，做盈亏归因与交易纪律复盘。

**数据来源**：QMT 实盘历史数据（`query_data` 接口直接查询券商，非 OMS 本地表）。数据为真实操作记录。

**数据纪律**：所有 MCP 工具均为**只读查询**，禁止触发任何交易操作。

---

## 可用工具

| MCP 分组 | 工具 | 用途 |
|---------|------|------|
| `positions` | `list_broker_positions` | 当前持仓（判断是否仍持有） |
| `positions` | `get_broker_position` | 指定标的当前持仓 |
| `positions` | `get_broker_asset` | 账户资产 |
| `positions` | `list_broker_orders` | 当日委托 |
| `positions` | `list_broker_trades` | 当日成交 |
| `positions` | `list_historical_trades` | 历史成交（QMT 券商数据，按标的+日期范围） |
| `positions` | `list_historical_orders` | 历史委托（QMT 券商数据，按标的+日期范围） |
| `positions` | `list_position_snapshots` | 持仓快照历史（QMT 券商数据，按标的+日期范围） |
| `stocks` | `get_stock_overview` | 当前行情（盈亏计算用） |

---

## 执行流程

### 场景 A：指定标的交易复盘

1. 并行调用 `list_historical_trades(symbol=...)` + `list_historical_orders(symbol=...)` + `get_broker_position`
2. 调用 `get_stock_overview` 获取当前价（用于浮盈浮亏计算）
3. 综合成交记录与委托记录，计算盈亏归因
4. 输出标的复盘报告

### 场景 B：全账户交易复盘

1. 并行调用 `list_historical_trades()` + `list_broker_positions` + `get_broker_asset`
2. 对每个持仓标的获取当前行情
3. 输出全账户复盘报告

### 场景 C：持仓变化追踪

1. 调用 `list_position_snapshots(symbol=...)`
2. 结合 `get_stock_overview` 当前行情
3. 输出持仓变化时序报告

### 场景 D：当日交易复盘

1. 并行调用 `list_broker_trades` + `list_broker_orders` + `list_broker_positions`
2. 对每笔成交计算盈亏
3. 输出当日复盘报告

| 日期 | 持仓量 | 成本价 | 市值 | 浮动盈亏 | 当日盈亏 |
|------|--------|--------|------|---------|---------|
| ... | ... | ... | ... | ... | ... |

## 交易纪律检查
- 是否追涨杀跌（买入时标的技术面信号）

- ...

## 迭代预算

| 阶段 | 轮次 |
|------|------|
| 并行取数 | 1 |
| 计算与推理 | 1~2 |
| 合计 | ≤ 4 |

## 约束

- 严禁触发任何下单、撤单操作
- 盈亏计算须基于实际成交价，禁止用收盘价替代成交价
- 交易纪律检查须引用具体数据（技术面信号/论点卡方向），不可泛泛而谈
- 历史查询默认返回最近 100 条；需更长时间范围时传 start_date/end_date 参数
