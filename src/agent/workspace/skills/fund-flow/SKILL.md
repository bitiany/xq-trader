# 个股资金面专项分析

## 触发条件

用户询问个股资金面相关问题时触发，例如：
- "XXX 资金面怎么样"
- "XXX 主力资金在流入还是流出"
- "XXX 有没有资金背离"
- "XXX 超大单情况"

> 本 skill 可被 stock-research 通过 spawn 委托执行（作为 Worker）。

## 可用工具

来自 MCP 分组 `xq_stocks`。

| 工具名 | 用途 | 关键参数 |
|--------|------|---------|
| `mcp_xq_stocks_xq_get_stock_fund_flow` | 主力资金流向（近 N 日超大/大/中/小单净流入） | `symbol` |

**调用规范**：
- `symbol` 必须带后缀（如 `688322.SH`）。
- 参数只能是 `{"symbol": "688322.SH"}` 形式，禁止传入 `limit` 等响应字段。

## 执行流程

1. **获取资金流数据**：调用 `get_stock_fund_flow` → 读取近 N 日主力/超大单/大单/中单/小单净流入数据。
2. **主力趋势判断**：连续多日主力净流入=持续关注信号；连续净流出=谨慎信号。
3. **超大单分析**：超大单净流入方向与力度，是否与股价方向一致。
4. **背离识别**：价格上涨但主力净流出（顶背离），或价格下跌但主力净流入（底背离）。
5. **综合资金结论**：资金面偏多/偏空/中性 + 简述。

## 输出格式

```
# {股票名称}（{股票代码}）资金面分析
> 数据截至：{trade_date}

## 一、主力资金概况
- 近 N 日主力净流入: {金额}
- 方向: 持续流入/持续流出/震荡

## 二、超大单分析
- 超大单净流入: {金额}
- 趋势: {描述}

## 三、资金与价格背离
- 背离类型: 顶背离/底背离/无背离
- 描述: {具体说明}

## 四、综合资金判断
- 方向: 偏多/偏空/中性
- 依据: {简述}
```

## 约束

1. 资金数据必须来自 `mcp_xq_stocks_xq_get_stock_fund_flow` 返回，严禁编造。
2. 背离判断须基于具体数据（价格方向 vs 资金方向），不可主观臆测。
3. 信号方向仅给「偏多/偏空/中性」方向性判断，不输出具体买卖建议。
4. 工具调用失败必须如实标注数据缺失。
