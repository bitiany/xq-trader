# 对比分析（跨公司 / 跨期）

## 触发条件

用户希望对比不同公司的经营状况，或同一公司不同时期的变化时触发。

## 可用工具

| MCP 分组 | 工具 | 用途 |
|---------|------|------|
| `stocks` | overview / financials / technical / fund_flow | 实时行情与财务取数 |
| `research_thesis` | `get_stock_thesis` | 读取各标的基本面方向（慢变量） |

## 执行流程

### 跨公司对比

1. **确认标的**：识别公司列表，转换为 symbol。
2. **并行取数**：
   - 每家公司：`get_stock_overview` + `get_stock_financials`
   - 每家公司：`get_stock_thesis`（若有论点卡，纳入基本面方向对比）
3. **对比维度**：估值 / 盈利 / 成长 / 财务健康 / 资金偏好 / **基本面方向（论点卡）**
4. **输出**：横向对比表 + 差异分析 + 综合结论。

论点卡方向来自 `research_thesis`，数字仍须来自 `stocks` 实时取数。

### 跨期对比

1. **确认标的与周期**。
2. **取数**：`get_stock_financials`（多期）+ 按需 `get_stock_technical`。
3. **论点卡**：`get_stock_thesis` 提供当前基本面方向基准；跨期数字以 financials 为准。
4. **输出**：变化幅度表 + 趋势研判。

## 输出要求

- 跨公司：含估值/盈利/成长/财务健康对比表 + 论点卡方向对比（若有）+ 综合评价。
- 跨期：含业绩变化表 + 趋势研判。
- 标注数据截至日期；论点卡引用标注 as-of。

## 约束

- 对比必须基于同一时间截面。
- 跨公司对比须同行业才有可比性，跨行业需标注「行业差异较大，仅供参考」。
- 论点卡方向仅供参考，对比数字必须来自实时 MCP 取数。
