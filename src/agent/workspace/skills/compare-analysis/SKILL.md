# 对比分析（跨公司 / 跨期）

## 触发条件

用户希望对比不同公司的经营状况，或同一公司不同时期的变化时触发，例如：
- "对比中芯国际和台积电的盈利能力"
- "茅台今年和去年业绩变化"
- "宁德时代和比亚迪谁更好"
- "XXX 和 YYY 哪个值得买"

## 可用工具

来自 MCP 分组 `xq_stocks`。

| 工具名 | 用途 | 关键参数 |
|--------|------|---------|
| `mcp_xq_stocks_xq_get_stock_overview` | 行情、估值、行业定位 | `symbol` |
| `mcp_xq_stocks_xq_get_stock_financials` | 财务摘要（利润/资产/现金流/指标） | `symbol` |
| `mcp_xq_stocks_xq_get_stock_kline` | K线走势（对比股价表现） | `symbol`, `limit` |
| `mcp_xq_stocks_xq_get_stock_fund_flow` | 资金流向（对比资金偏好） | `symbol`, `limit` |

## 执行流程

### 跨公司对比

1. **确认标的**：识别用户要对比的公司列表，转换为 symbol。
2. **并行取数**：对每家公司并行调用 `mcp_xq_stocks_xq_get_stock_overview` + `mcp_xq_stocks_xq_get_stock_financials`。
3. **对比维度**：
   - 估值对比：PE / PB / PS / 股息率 / 市值
   - 盈利对比：ROE / 毛利率 / 净利率
   - 成长对比：营收增速 / 净利增速
   - 财务健康：资产负债率 / 经营现金流 / 流动比率
   - 资金偏好：主力净流入趋势
4. **输出对比表**：横向对比表格 + 差异分析 + 各自优势劣势。

### 跨期对比

1. **确认标的与周期**：识别 symbol 与对比时间段（如今年 vs 去年、Q1 vs Q4）。
2. **取数**：调用 `mcp_xq_stocks_xq_get_stock_financials` 获取财务数据（含多期）。
3. **对比维度**：
   - 业绩变化：营收/净利同比、环比
   - 盈利能力变化：ROE/毛利率趋势
   - 财务健康变化：负债率/现金流趋势
   - 股价表现：调用 `mcp_xq_stocks_xq_get_stock_kline` 对比不同时期走势
4. **输出趋势分析**：变化幅度表 + 趋势判断 + 原因分析。

## 输出格式

### 跨公司对比

```
# {公司A} vs {公司B} 对比分析
> 数据截至：{trade_date}

## 一、估值对比
| 指标 | {公司A} | {公司B} | 差异 |
|------|---------|---------|------|
| PE(TTM) | {值} | {值} | {值} |
| PB | {值} | {值} | {值} |

## 二、盈利能力对比
{ROE/毛利率/净利率对比表}

## 三、成长性对比
{营收/净利增速对比表}

## 四、财务健康对比
{负债率/现金流/流动比率对比表}

## 五、综合评价
- {公司A}优势：{具体}
- {公司B}优势：{具体}
- 结论：{综合判断}
```

### 跨期对比

```
# {股票名称}（{股票代码}）跨期对比
> 对比周期：{周期A} vs {周期B}

## 一、业绩变化
| 指标 | {周期A} | {周期B} | 变化幅度 |
|------|---------|---------|---------|
| 营收 | {值} | {值} | {同比/环比} |

## 二、盈利能力变化
{ROE/毛利率趋势}

## 三、趋势研判
{业绩趋势判断与原因分析}
```

## 约束

- 对比必须基于同一时间截面，不可用不同时期数据做横向对比。
- 跨公司对比须同行业才有可比性，跨行业需标注"行业差异较大，仅供参考"。
- 所有数值来自工具返回，严禁编造。
- 输出遵守 AGENTS.md Markdown 排版规范，段落间最多 1 空行。
- 不给出具体买卖建议。

## 示例对话

用户: "对比中芯国际和台积电的盈利能力"
步骤:
1. 识别 symbols: 688981.SH, TSM
2. 并行调用 `mcp_xq_stocks_xq_get_stock_financials`（两家）
3. 输出 ROE/毛利率/净利率对比表
4. 标注"行业相同但规模差异大，仅供参考"

用户: "茅台今年和去年业绩变化"
步骤:
1. 识别 symbol = 600519.SH
2. 调用 `mcp_xq_stocks_xq_get_stock_financials`（含多期数据）
3. 计算营收/净利同比变化
4. 输出跨期对比表与趋势研判
