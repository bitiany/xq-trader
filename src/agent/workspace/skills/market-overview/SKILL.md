# 大盘与板块概览

## 触发条件

用户询问大盘行情、市场走势、板块表现、市场情绪时触发，例如：
- "大盘怎么样"
- "今天市场走势如何"
- "哪些板块涨得好"
- "市场情绪如何"

## 可用工具

来自 MCP 分组 `xq_stocks` 与 web 工具。

| 工具名 | 用途 | 关键参数 |
|--------|------|---------|
| `mcp_xq_stocks_xq_get_stock_kline` | 指数K线（上证/深证/创业板/科创50） | `symbol`, `limit` |
| `mcp_xq_stocks_xq_get_stock_overview` | 指数概况（点位/涨跌幅/成交额） | `symbol` |
| `mcp_xq_stocks_xq_get_stock_fund_flow` | 指数资金流向 | `symbol`, `limit` |
| `web_search` | 搜索市场要闻、板块异动、政策动态 | `query` |

## 执行流程

1. **确认范围**：用户问"大盘"默认看上证指数 + 创业板指；问"板块"走板块分析流程。
2. **指数行情**：调用 `mcp_xq_stocks_xq_get_stock_overview` 获取指数点位、涨跌幅、成交额。
3. **趋势分析**：调用 `mcp_xq_stocks_xq_get_stock_kline`（limit=20）获取近 20 日 K 线，分析趋势。
4. **资金面**：调用 `mcp_xq_stocks_xq_get_stock_fund_flow` 看主力资金流向。
5. **市场要闻**：调用 `web_search`（query="今日A股市场要闻 板块异动"）补充市场动态。
6. **输出报告**：指数表现 + 趋势判断 + 板块亮点 + 资金面 + 市场情绪。

## 输出格式

```
# 市场概览
> 数据截至：{trade_date}

## 一、指数表现
| 指数 | 点位 | 涨跌幅 | 成交额 |
|------|------|--------|--------|
| 上证指数 | {值} | {值} | {值} |
| 创业板指 | {值} | {值} | {值} |

## 二、趋势研判
{近20日K线趋势分析：多空排列、均线状态、量价配合}

## 三、资金面
{主力资金净流入/流出趋势}

## 四、板块表现
{今日强势/弱势板块，来自web_search}

## 五、市场要闻
{重要市场新闻摘要，标注来源}

## 六、市场情绪
- 情绪判断：{贪婪/中性/恐慌}
- 依据：{涨跌家数、量能、资金流向综合判断}
```

## 约束

- 指数数据必须来自工具返回，严禁编造。
- 板块表现如无直接数据源，用 `web_search` 补充并标注来源。
- 市场情绪判断须基于多项指标综合分析，不可单一指标定论。
- 输出遵守 AGENTS.md Markdown 排版规范，段落间最多 1 空行。
- 不给出具体买卖建议，仅提供市场概览参考。

## 示例对话

用户: "大盘怎么样"
步骤:
1. 调用 `mcp_xq_stocks_xq_get_stock_overview`（symbol="000001.SH"）
2. 调用 `mcp_xq_stocks_xq_get_stock_overview`（symbol="399006.SZ"）
3. 调用 `mcp_xq_stocks_xq_get_stock_kline`（symbol="000001.SH", limit=20）
4. 调用 `mcp_xq_stocks_xq_get_stock_fund_flow`（symbol="000001.SH"）
5. 调用 `web_search`（query="今日A股市场要闻 板块异动"）
6. 输出市场概览报告

用户: "今天哪些板块涨得好"
步骤:
1. 调用 `web_search`（query="今日A股板块涨幅排名"）
2. 整理板块表现，标注来源
3. 对热门板块中的龙头股调用 `mcp_xq_stocks_xq_get_stock_overview` 补充详情
