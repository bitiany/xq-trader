# 券商研报分析

## 触发条件

用户询问券商研报/分析师观点相关问题时触发，例如：
- "XXX 最近有哪些研报"
- "分析师怎么看 XXX"
- "XXX 评级怎么样/目标价多少"
- "XXX 盈利预测/一致预期"
- "卖方对 XXX 的观点"

## 可用工具

来自 MCP 分组 `xq_research`（研报）与 `xq_stocks`（交叉验证）。

| 工具名 | 职责 | 关键参数 |
|--------|------|---------|
| `mcp_xq_research_xq_list_stock_research_reports` | 个股研报列表（机构/分析师/评级/评级变动/盈利预测） | `symbol`, `page`, `page_size` |
| `mcp_xq_research_xq_get_research_report` | 单篇研报详情（摘要/全文） | `info_code` |
| `mcp_xq_stocks_xq_get_stock_financials` | 财务摘要（交叉验证研报观点） | `symbol` |
| `mcp_xq_stocks_xq_get_stock_valuation` | 估值诊断（对比研报目标价空间） | `symbol` |
| `web_search` | 补充最新卖方一致预期/评级变动 | `query` |

## 执行流程

1. **拉取研报列表**：调用 `list_stock_research_reports`(symbol, page_size=20) → 获取近期研报清单。
2. **评级梳理**：从列表统计评级分布（买入/增持/中性/...）与评级变动（上调/下调/维持/首次），判断卖方共识方向。
3. **盈利预测共识**：汇总 `eps_forecast` 数组 → 计算未来年度 EPS/PE 一致预期区间。
4. **重点研报深读**：对评级变动显著或最新的 1-2 篇，调用 `get_research_report`(info_code) 读取摘要/全文，提取核心逻辑。
5. **交叉验证**：调用 `get_stock_financials` 对比研报预测与实际财务数据；调用 `get_stock_valuation` 对比当前估值与研报目标价隐含空间。
6. **综合输出**：卖方观点汇总 + 共识方向 + 预期差 + 交叉验证结论。

## 输出要求

`# {股票名称}（{代码}）券商研报观点汇总`，含五节：
1. **研报清单**：近期研报列表（标题/机构/分析师/评级/评级变动/日期，表格）
2. **评级共识**：评级分布 + 评级变动趋势 + 共识方向
3. **盈利预测**：未来年度 EPS/PE 一致预期区间（表格）
4. **核心观点**：重点研报摘要（1-2 篇的核心逻辑）
5. **交叉验证**：研报预测 vs 平台实际财务 + 当前估值 vs 目标价空间 + 一致性判断

标注研报发布日期；研报观点须与平台数据交叉验证，矛盾处明确说明。

## 约束

1. 研报数据必须来自 `mcp_xq_research_xq_*` 工具返回，严禁编造评级与预测数字。
2. 盈利预测须标注来源机构与发布日期。
3. 研报观点仅为卖方参考，须与平台财务/估值数据交叉验证，不盲从。
4. 研报列表为空时显式标注"暂无已采集研报"，并用 `web_search` 补充。
5. 不输出具体买卖建议；仅汇总卖方观点与一致性判断。

## 示例对话

用户: "紫光国微最近有哪些研报"
步骤:
1. 调用 `list_stock_research_reports`(002049.SZ, page_size=20)
2. 整理研报清单 + 评级共识 + 盈利预测
3. 对最新研报调用 `get_research_report`(info_code) 读取摘要
4. 调用 `get_stock_financials` + `get_stock_valuation` 交叉验证
5. 输出研报观点汇总报告

用户: "分析师怎么看茅台"
步骤:
1. 调用 `list_stock_research_reports`(600519.SH)
2. 统计评级分布与变动 → 卖方共识方向
3. 汇总盈利预测一致预期
4. 交叉验证 → 输出综合观点
