# 舆情与情绪面分析

## 触发条件

用户询问某股票的近期新闻、舆情风向、重大事件影响、市场情绪时触发，例如：
- "XXX 最近有什么新闻"
- "XXX 最近的舆情怎么样"
- "XXX 有资产重组的消息吗"
- "市场情绪如何"

## 可用工具

来自 MCP 分组 `xq_stocks` 与 web 工具。

| 工具名 | 用途 | 关键参数 |
|--------|------|---------|
| `mcp_xq_stocks_xq_get_stock_news` | 个股新闻列表 | `symbol` |
| `mcp_xq_stocks_xq_get_stock_announcements` | 个股公告列表 | `symbol` |
| `mcp_xq_stocks_xq_get_stock_fund_flow` | 资金流向（验证情绪） | `symbol`, `limit` |
| `web_search` | 搜索市场情绪、行业政策、突发事件 | `query` |
| `web_fetch` | 抓取指定新闻全文 | `url` |

## 关键词体系

### 利好类
资产重组、回购、业绩预增、股权激励、大额订单、战略合作、增持、政策扶持

### 利空类
业绩预减、违规处罚、股东减持、商誉减值、退市风险、诉讼仲裁、监管问询

### 政策类
降准降息、产业政策、监管新规、财政刺激、贸易政策、行业整顿

## 情感分类方法（Qwen3 金融语境）

本 skill 不依赖外部情感分析模型（如 FinBERT，仅支持英文且商用授权受限），
直接由当前 agent（Qwen3-235B，65536 上下文）通过结构化 prompt 完成金融情感分类。

### 分类标签

| 标签 | 含义 | 强度范围 |
|------|------|----------|
| positive | 利好/正面事件 | 1（弱）-5（强） |
| negative | 利空/负面事件 | 1（弱）-5（强） |
| neutral | 中性/信息类 | 0 |

### 批量分类 prompt 模板

对拉取到的 N 条新闻/公告，按以下模板批量分类（单次调用，避免逐条请求）：

```
你是 A 股金融舆情分析师。请对以下新闻逐条做情感分类。

输出 JSON 数组，每条包含：
- index: 序号（从 1 开始）
- sentiment: positive / negative / neutral
- intensity: 1-5（neutral 固定为 0）
- event_type: 重组/回购/业绩/减持/处罚/政策/其他
- summary: 一句话摘要（≤30 字）

新闻列表：
1. {标题1} — {内容片段1}
2. {标题2} — {内容片段2}
...

仅输出 JSON，不要额外解释。
```

### 情绪指数计算

将分类结果按以下规则汇总为情绪指数：

- **贪婪**：正面条数占比 ≥ 60% 且平均强度 ≥ 3
- **恐慌**：负面条数占比 ≥ 60% 且平均强度 ≥ 3
- **中性**：其余情况

情绪指数 = (正面强度和 - 负面强度和) / (正面条数 + 负面条数 + 1)

## 执行流程

1. **获取新闻**：调用 `mcp_xq_stocks_xq_get_stock_news` 拉取个股近期新闻。
2. **获取公告**：调用 `mcp_xq_stocks_xq_get_stock_announcements` 拉取近期公告。
3. **补充搜索**：如新闻不足，用 `web_search` 搜索 "{股票名称} 最新消息" / "{股票名称} 重大事件"。
4. **情感分类**：按"情感分类方法"中的 prompt 模板，对新闻+公告批量做情感分类，得到每条的 sentiment/intensity/event_type。
5. **情绪研判**：
   - 基于分类结果识别重大事件（利好/利空/政策），分类归集
   - 按"情绪指数计算"规则汇总生成情绪指数（贪婪/中性/恐慌）
6. **交叉验证**：调用 `mcp_xq_stocks_xq_get_stock_fund_flow` 看资金流向是否与情绪一致（如利好但资金流出，需提示分歧）。
7. **输出报告**：新闻摘要 + 情绪研判 + 事件驱动信号 + 风险提示。

## 输出格式

```
# {股票名称}（{股票代码}）舆情与情绪面分析
> 数据截至：{trade_date}

## 一、新闻摘要
{近期重要新闻列表，每条标注来源与日期}

## 二、公告要点
{近期关键公告摘要}

## 三、情绪研判
- 情绪指数：{贪婪/中性/恐慌}
- 利好因素：{具体事件}
- 利空因素：{具体事件}
- 政策影响：{政策类事件}

## 四、事件驱动信号
- 信号类型：{买入/卖出/观望}
- 依据：{事件与资金流向综合判断}

## 五、风险提示
{需关注的潜在风险}
```

## 约束

- 新闻仅作辅助参考，不替代平台结构化数据。
- 情绪判断须基于具体新闻内容，不可凭空推断。
- 资金流向与情绪矛盾时必须提示分歧。
- 输出遵守 AGENTS.md Markdown 排版规范，段落间最多 1 空行。
- 不给出具体买卖建议，仅提供情绪面参考。

## 示例对话

用户: "比亚迪最近有什么新闻"
步骤:
1. 调用 `mcp_xq_stocks_xq_get_stock_news`（symbol="002594.SZ"）
2. 调用 `mcp_xq_stocks_xq_get_stock_announcements`（symbol="002594.SZ"）
3. 按批量分类 prompt 模板对新闻+公告做情感分类
4. 汇总情绪指数（贪婪/中性/恐慌）
5. 调用 `mcp_xq_stocks_xq_get_stock_fund_flow`（symbol="002594.SZ"）交叉验证
6. 输出舆情报告

用户: "最近半导体行业有什么政策利好"
步骤:
1. 调用 `web_search`（query="半导体行业 最新政策利好"）
2. 对搜索结果做情感分类，标注 event_type=policy
3. 整理政策类新闻，标注来源与日期
4. 筛选受益标的，输出政策影响分析
