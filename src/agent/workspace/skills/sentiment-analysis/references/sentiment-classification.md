# 情感分类与情绪指数方法

> 本文件由 sentiment-analysis SKILL 按需加载，承载金融情感分类的方法论与 prompt 模板。agent 在执行舆情分析时通过 `read_file` 读取本文件，按下列方法对新闻/公告做情感分类与情绪指数计算。

## 关键词体系

### 利好类
资产重组、回购、业绩预增、股权激励、大额订单、战略合作、增持、政策扶持

### 利空类
业绩预减、违规处罚、股东减持、商誉减值、退市风险、诉讼仲裁、监管问询

### 政策类
降准降息、产业政策、监管新规、财政刺激、贸易政策、行业整顿

## 分类标签

| 标签 | 含义 | 强度范围 |
|------|------|----------|
| positive | 利好/正面事件 | 1（弱）-5（强） |
| negative | 利空/负面事件 | 1（弱）-5（强） |
| neutral | 中性/信息类 | 0 |

## 批量分类 prompt 模板

对拉取到的 N 条新闻/公告，按以下模板批量分类（单次调用，避免逐条请求）：

```
你是 A 股金融舆情分析师。请对以下新闻逐条做情感分类。

输出 JSON 数组，每条包含：
- index: 序号（从 1 开始）
- sentiment: positive / negative / neutral
- intensity: 1-5（neutral 固定为 0）
- event_type: 重组/回购/业绩/减持/处罚/政策/其他
- summary: 一句话摘要（≤30 字）

新闻列表：
1. {标题1} — {内容片段1}
2. {标题2} — {内容片段2}
...

仅输出 JSON，不要额外解释。
```

## 情绪指数计算

将分类结果按以下规则汇总为情绪指数：

- **贪婪**：正面条数占比 ≥ 60% 且平均强度 ≥ 3
- **恐慌**：负面条数占比 ≥ 60% 且平均强度 ≥ 3
- **中性**：其余情况

情绪指数 = (正面强度和 - 负面强度和) / (正面条数 + 负面条数 + 1)
