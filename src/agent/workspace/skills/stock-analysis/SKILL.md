# 个股全方位分析（五步法）

基于华泰证券投研方法论与业界主流分析框架，采用"自上而下定赛道、自下而上验公司、定性定量相结合"的五步分析法。

## 触发条件

当用户要求对某只股票进行分析、诊断、评估、解读时触发此技能。包括但不限于：
- "分析一下 XXX"
- "XXX 这只股票怎么样"
- "帮我看看 XXX 的基本面/技术面"
- "对 XXX 做个全面分析"

## 可用工具

| 工具名 | 用途 | 返回内容 |
|--------|------|----------|
| `get_stock_overview` | 行情与估值 | 名称、行业、最新价、涨跌幅、PE/PB/PS、市值、公司简介 |
| `get_stock_financials` | 财务数据 | 利润表/资产负债表/现金流量表/财务指标摘要 |
| `get_stock_technicals` | 技术面 | 近期K线、MA/MACD/KDJ/RSI/BIAS指标、换手率 |
| `get_stock_fund_flow` | 资金流向 | 主力/超大单/大单/中单/小单净流入额及趋势 |
| `get_stock_position` | 持仓信息 | 当前持仓数量、成本价、浮盈浮亏（无持仓则跳过） |
| `web_search` | 网络搜索 | 搜索个股相关新闻、公告、研报等资讯 |
| `web_fetch` | 网页抓取 | 抓取指定URL的网页内容 |

## 执行流程

按以下五步顺序执行，每步必须调用对应工具获取数据，严禁编造。

**重要：工具调用规范**
- 每次只调用一个工具，严禁在一次调用中合并多个工具的参数
- `web_search` 只接受 `{"query": "搜索关键词"}` 格式，不要传入 symbol 或其他参数
- `get_stock_fund_flow` 接受 `{"symbol": "600519.SH", "limit": 10}` 格式
- 不要将多个工具的参数合并到一个工具调用中

### 第一步：行业赛道分析 — 先定赛道，再选公司

**调用工具**：`get_stock_overview`

分析要点：
1. **行业定位**：公司所属行业与细分赛道，行业处于何种生命周期（导入期/成长期/成熟期/衰退期）
2. **行业竞争格局**：行业集中度、公司行业地位（龙头/挑战者/跟随者）
3. **行业空间与增速**：行业整体市场规模与增长趋势
4. **政策与宏观环境**：行业是否受政策支持或监管约束

> 注：行业深度数据需基于公司简介与行业标签进行逻辑推演，明确标注"基于公开信息推断"。

### 第二步：基本面分析 — 验证公司质地

**调用工具**：`get_stock_overview` + `get_stock_financials`（可并行调用）

分析要点：

#### 2.1 商业模式与护城河
- 公司靠什么赚钱（产品/服务/平台）
- 竞争壁垒判断：技术壁垒/品牌壁垒/成本壁垒/网络效应/牌照壁垒
- 主营业务集中度与多元化风险

#### 2.2 盈利能力
- ROE（净资产收益率）：连续性及趋势，>15%为优秀
- 毛利率：反映产品定价权与竞争力
- 净利率：反映成本控制能力
- 与行业均值对比

#### 2.3 成长性
- 营收增速与净利润增速是否同步（增收又增利 vs 增收不增利）
- 成长驱动因素是否可持续

#### 2.4 财务健康度
- 资产负债率：一般行业<60%安全，金融/地产可适当放宽
- 经营活动现金流：是否持续为正，与净利润匹配度（盈利质量）
- 流动比率/速动比率：短期偿债能力

#### 2.5 风险排查（排雷）
- 商誉规模与净利润比例（>2倍为高风险）
- 股权质押率（>25%警惕强平风险）
- 主营业务占比（<80%需警惕蹭热点）
- 净利润与现金流背离（利润多为"欠条"需警惕）

### 第三步：估值分析 — 好公司也要好价格

**调用工具**：`get_stock_overview`（估值数据已在第一步获取，无需重复调用）

分析要点：
1. **PE（市盈率）**：当前PE与行业均值对比，PE-TTM更反映真实估值
2. **PB（市净率）**：重资产行业重点参考，<1可能破净
3. **PS（市销率）**：亏损企业或高成长企业参考指标
4. **股息率（dv_ratio）**：价值股的重要参考
5. **市值规模**：总市值与流通市值，判断流动性
6. **估值综合判断**：高估/合理/低估，需结合行业特性与成长性综合判断

> 估值无绝对标准，需结合行业特性（科技股PE普遍高于银行股）、成长阶段（高成长可给更高估值）综合判断。

### 第四步：技术面与资金面分析 — 找对入场时机

**调用工具**：先调用 `get_stock_technicals`，再调用 `get_stock_fund_flow`（分步调用，不要并行）

#### 4.1 趋势判断
- 均线排列：多头排列（MA5>MA10>MA20>MA60）/ 空头排列 / 粘合震荡
- 均线金叉/死叉信号

#### 4.2 动量与振荡指标
- MACD：DIF/DEA位置关系、柱状线变化方向、顶底背离信号
- KDJ：超买区（>80）/ 超卖区（<20）、金叉/死叉
- RSI：强弱区间（>70超买 / <30超卖）、背离信号
- BIAS：乖离率偏离程度，极端值预示回归

#### 4.3 量价关系
- 成交量变化趋势（放量/缩量/地量）
- 量价配合：上涨放量/下跌缩量为健康，上涨缩量需警惕
- 换手率水平：高换手（>10%）活跃、低换手（<3%）冷清

#### 4.4 资金流向分析
- 主力资金净流入/流出趋势（连续流入/流出天数）
- 超大单与大单动向：主力资金方向，持续流入看多，持续流出看空
- 中单与小单动向：散户行为，与主力方向相反时需警惕
- 主力净流入占比：判断资金流入/流出的相对强度

#### 4.5 关键价位
- 近期支撑位与压力位（基于近期高低点与均线位置判断）

### 第五步：综合评估与决策参考

**调用工具**：先调用 `get_stock_position`，再调用 `web_search`（分步调用，不要并行）

#### 5.1 新闻资讯与事件驱动
- 使用 `web_search` 搜索近期相关新闻，关键词示例："{股票名称} 最新消息"、"{股票名称} 公告"、"{股票名称} 研报"
- 筛选与股价走势相关的重大事件（业绩预告、重大合同、政策变化、行业事件等）
- 判断新闻事件对股价的可能影响（利好/利空/中性）
- 若搜索结果中有重要研报或公告，可用 `web_fetch` 抓取详细内容

#### 5.2 持仓分析（仅在有持仓时）
- 持仓成本与当前价位对比
- 浮动盈亏及盈亏比例
- 仓位建议（基于技术面和基本面综合判断）

#### 5.3 多维度综合评分

| 维度 | 权重 | 评分依据 |
|------|------|----------|
| 行业赛道 | 15% | 行业空间、竞争格局、政策环境 |
| 基本面 | 25% | 盈利能力、成长性、财务健康、护城河 |
| 估值 | 15% | PE/PB分位、与行业对比、市值合理性 |
| 技术面 | 15% | 趋势方向、指标信号、量价配合 |
| 资金面 | 15% | 主力资金动向、超大单/大单趋势 |
| 风险 | 10% | 排雷结果、持仓风险、行业风险 |
| 新闻事件 | 5% | 近期重大事件影响 |

评分等级：优秀（80-100）/ 良好（60-79）/ 一般（40-59）/ 较差（0-39）

#### 5.4 风险提示
- 主要风险因素（行业/公司/市场层面）
- 需重点跟踪的事件或指标变化

#### 5.5 关注要点
- 近期需跟踪的关键事件
- 重要的技术位与时间窗口

```
## 一、行业赛道分析
{第一步分析内容}

## 二、基本面分析
### 2.1 商业模式与护城河
### 2.2 盈利能力
### 2.3 成长性
### 2.4 财务健康度
### 2.5 风险排查

## 三、估值分析
{第三步分析内容}

## 四、技术面与资金面分析
### 4.1 趋势判断
### 4.2 动量与振荡指标
### 4.3 量价关系
### 4.4 资金流向分析
### 4.5 关键价位

## 五、综合评估

### 5.5 关注要点
```

## 约束

1. 所有数字必须来自工具返回数据，严禁编造行情、财务或指标数值
2. 不给出具体买卖建议，仅提供分析参考
3. 明确标注数据来源与时效性（如"截至 YYYY-MM-DD"）
4. 技术指标解读需结合趋势背景，避免孤立解读单一指标
5. 若某工具调用失败，在报告中注明数据缺失，不可凭空补充
6. 持仓为空时，明确说明"当前无持仓，跳过持仓分析"
7. 估值判断必须结合行业特性，不可用统一标准衡量所有行业
8. 风险排查必须先于收益分析，排雷优先
9. 网络搜索结果需标注来源，仅作为辅助参考，不作为核心分析依据
10. 资金流向数据需结合股价走势综合判断，不可孤立解读
