# 个股前瞻性推演（国泰君安五步法）

## 触发条件

用户要求对某只股票进行分析、诊断、评估、解读、推演时触发，例如：
- "分析一下 XXX"
- "XXX 这只股票怎么样"
- "帮我推演一下 XXX 的投资逻辑"
- "XXX 有没有超预期机会"
- "对 XXX 做个前瞻性分析"

## 核心理念

> **五步法不是对历史的总结，而是对未来的前瞻性推演。** 从公开数据中提取市场未充分定价的信息，推导与市场主流不同的投资逻辑，判断新逻辑下的基本面是否显著超越一致预期，找到点燃超预期差的具体事件与时点，最终形成方向性投资决策参考。

## 分析场景

识别用户意图后选择场景，按对应流程执行：

| 场景 | 触发词 | 主流程 |
|------|--------|--------|
| 1 个股深度报告 | "深度分析/五步法/推演 + 某公司" | 前瞻性五步法（下文） |
| 2 季报速评 | "季报/刚发了财报/业绩点评" | 预期差聚焦（financials + research + 一致预期） |
| 3 行业比较 | "对比/谁更好/哪个值得买" | 多公司 overview+financials+valuation 横向对比 |
| 4 事件驱动 | "政策/突发事件/听说..." | news+announcements + web_search 传导分析 |
| 5 财务异常挖掘 | "异常/风险/现金流有问题" | financials 拆分 + fund_flow 背离 + 异常信号扫描 |

### 场景2 季报速评
**调用**：`get_stock_financials` + `list_stock_research_reports`（最新研报评级/预测）+ `get_stock_news` + `web_search` "{股票名称} 业绩 一致预期"。
**输出**：最新财报核心指标 → 市场预期对比（预期差方向+幅度） → 研报评级变动 → 一句话点评。

### 场景3 行业比较
**调用**：对每个公司并行 `get_stock_overview` + `get_stock_financials` + `get_stock_valuation`；`web_search` "{行业} 估值对比 增长前景"。
**输出**：多公司核心指标对比表（营收增速/净利增速/毛利率/ROE/PE/PB） → 行业趋势 → 推序与理由。

### 场景4 事件驱动
**调用**：`get_stock_news` + `get_stock_announcements` + `web_search` 事件详情 + 受益/受损标的。
**输出**：事件解读 → 受益/受损标的筛选 → 传导路径 → 催化剂时间轴。

### 场景5 财务异常挖掘
**调用**：`get_stock_financials`（多期拆分）+ `get_stock_fund_flow`（资金面背离）+ `get_stock_valuation`（估值分位）+ `web_search` "{股票名称} 财务风险 异常"。
**要点**：应收/存货异常变动、现金流与利润背离、毛利率异常、商誉/质押、资金面与基本面背离。
**输出**：异常信号清单（每条标注数据依据+严重度） → 风险结论。

## 执行流程（前瞻性五步法 — 场景1 个股深度报告）

### 第一步：与众不同的信息差

> 目标：从公开数据中提取市场主流尚未充分关注、忽视或误读的**边际信息**。

**调用**：并行调用 `mcp_xq_stocks_xq_get_stock_overview` + `mcp_xq_stocks_xq_get_stock_financials` + `mcp_xq_stocks_xq_get_stock_news` + `mcp_xq_stocks_xq_get_stock_announcements` + `mcp_xq_stocks_xq_get_stock_fund_flow`。

要点（从工具返回中挖掘以下 4 类信息差）：
1. **财报里的边际变化**：被忽视的细分项——新业务收入占比拐点、毛利率拆分里的隐藏改善、费用率下行趋势、现金流与利润背离信号、存货/应收异常变动。
2. **公告里的前瞻信号**：股权激励行权条件（隐含业绩底线）、回购注销、高管/大股东增持计划、产能投产公告、重大合同/订单、资产重组进展。
3. **资金面与基本面的背离**：主力持续净流入但市场情绪冷淡、北向/融资盘异动、超大单与中小单方向背离。
4. **行业与上下游传导**：政策窗口、上游价格拐点、竞品动向对该公司的影响传导（结合 overview 行业标签与 web_search 补充）。

> 输出 2-3 条「市场未充分定价的信息」，每条标注信息来源（财报科目/公告条款/资金流指标/行业信号）与市场当前定价状态（未关注/误读/部分定价）。

### 第二步：与众不同的逻辑差

> 目标：基于第一步的信息差，推导与市场主流**不同**的投资逻辑，并做自洽性检验。

**调用**：复用第一步数据推演（无需新调用）；如需补充行业逻辑可 `web_search` "{行业} 投资逻辑 拐点"。

要点：
1. **市场主流逻辑**：从估值分位（overview 的 PE/PB 分位）、新闻基调、卖方一致预期推断市场当前如何定价该公司（如「被视为成熟期增长放缓」）。
2. **差异逻辑**：用第一步的信息差支撑另一种叙事（如「新业务占比拐点已被忽视，实际处于第二增长曲线起点」）。
3. **自洽性检验**：若差异逻辑成立，应观察到哪些指标变化？实际财务数据是否吻合？若关键指标反证，须明确标注差异逻辑存疑。

> 输出「主流逻辑 vs 差异逻辑」对照，标注差异逻辑的证据链与自洽性检验结论。

### 第三步：超预期差

> 目标：判断差异逻辑推导出的业绩/基本面，是否**显著超越**市场一致预期，并量化超预期幅度。

**调用**：`mcp_xq_stocks_xq_get_stock_kline`（看估值分位与技术面位置）+ `mcp_xq_stocks_xq_get_stock_diagnosis`（辅助交叉验证）；如需一致预期可 `web_search` "{股票名称} 业绩预测 一致预期"。

要点：
1. **市场一致预期锚点**：财报增速趋势外推、股权激励行权条件隐含的业绩底线、卖方一致预期（若有，标注来源）。
2. **差异逻辑下的业绩推演**：定量或半定量推演——新业务收入 × 毛利率 → 增量利润；产能投产 → 收入弹性；费用率下行 → 利润率改善。必须基于工具返回的财务数据，不凭空假设。
3. **超预期幅度**：超预期幅度 = 差异推演值 − 一致预期，标注方向（向上/向下）与幅度量级（显著/温和/无）。

> 输出「一致预期 vs 差异推演」对照表与超预期幅度判断。

### 第四步：催化剂

> 目标：找到能点燃超预期差、让市场从「无视」转向「共识」的**具体事件或时间点**。

**调用**：`web_search` "{股票名称} 事件日历/财报披露日/解禁/分红" + 复用第一步 news/announcements。

要点：
1. **已确定的事件日历**：财报披露日、产能投产日、限售解禁日、分红除权日、政策窗口、产品发布日。
2. **潜在催化剂**：行业拐点信号、竞品动向、上游价格拐点、政策落地节点。
3. **传导路径**：每个催化剂标注——预期触发时间、对超预期差的传导路径（如何让市场重新定价）。

> 输出催化剂清单与时间轴，按确定性排序。

### 第五步：结论与投资计划参考

> 目标：综合前四步形成**方向性**投资决策参考。合规边界：不输出具体买卖价位、仓位与止损，仅给方向判断、核心假设、证伪条件与跟踪框架。

**调用**：`mcp_xq_positions_xq_get_broker_position`（按需，仅在用户提及持仓时）。

要点：
1. **综合方向判断**：关注 / 观望 / 谨慎（三选一），一句话理由。
2. **核心假设**：差异逻辑成立的关键前提（1-2 条）。
3. **证伪条件**：什么数据/信号出现则差异逻辑失效，需退出观察。
4. **跟踪指标清单**：后续需持续观察的量化指标（如新业务收入占比、毛利率、主力资金流、特定催化剂落地）。
5. **关键观察时点**：第四步催化剂的触发时间窗口。
6. **持仓分析**（按需）：仅当用户提及持仓时调用工具并分析。
7. **风险提示**：具体风险点（商誉、质押、行业政策反转、差异逻辑证伪风险等），不可泛泛而谈。

## 约束

1. 所有数字必须来自工具返回，严禁编造；一致预期与卖方预测须标注来源。
2. **前瞻性优先**：每步都要指向未来推演，避免只做历史财务总结。
3. **信息差须可证伪**：每条信息差标注明确来源，不主观臆测。
4. **合规底线**：不输出具体买卖价位、仓位与止损；仅给方向性判断（关注/观望/谨慎）与跟踪框架。
5. 工具调用失败必须如实标注数据缺失。
6. 持仓为空时显式标注"当前无持仓"。
7. 差异逻辑自洽性检验不通过时，须明确降级方向判断（不得强行看多）。

## 示例对话

用户: "分析一下贵州茅台"
步骤:
1. 识别 symbol = 600519.SH
2. 并行调用 `overview` + `financials` + `news` + `announcements` + `fund_flow`（信息差原料）
3. 从返回中提取 2-3 条市场未充分定价的信息差
4. 复用数据推演市场主流逻辑 vs 差异逻辑，做自洽性检验
5. 调用 `kline` + `diagnosis`，结合一致预期推演超预期幅度
6. `web_search` "贵州茅台 事件日历/财报披露日" 补充催化剂
7. 按需调用 `get_broker_position`
8. 按五步法输出前瞻性推演报告

用户: "帮我推演比亚迪的投资逻辑"
步骤:
1. 识别 symbol = 002594.SZ
2. 并行调用五工具取数
3. 聚焦新业务（智能化/海外）占比拐点、毛利率拆分、产能投产公告作为信息差
4. 推演差异逻辑（如「海外+智能化第二增长曲线未被充分定价」）并自洽性检验
5. 推演超预期幅度与催化剂时间轴
6. 输出方向性判断与跟踪框架
